Komut Satırı (CLI) ve Açık Veri Kılavuzu

Terminal meraklıları, araştırmacılar ve veri analistleri için Python CLI araçları.

Python CLI ile Hızlı Kullanım

# Kütüphane İstatistiklerini Görüntüle
python -m kutsal_esik stats

# Rastgele Bir Felsefi Alıntı Çek
python -m kutsal_esik quote

# Belirli Bir Tema veya Kültüre Göre Alıntı Filtrele
python -m kutsal_esik quote --culture "Yunan"
python -m kutsal_esik quote --theme "Cömertlik"

# Tüm Koleksiyonda Arama Yap
python -m kutsal_esik search "Derrida"

# Kronolojiyi Terminalde Listele
python -m kutsal_esik timeline

# BibTeX Kaynakçasını Dışa Aktar
python -m kutsal_esik bib --export

# Yerel Web Sunucusunu Başlat
python -m kutsal_esik serve --port 8000

Açık Veri Dosyaları (JSON)

Bu repodaki tüm veriler makine tarafından okunabilir açık JSON formatında data/ dizininde barındırılmaktadır:

  • data/quotes.json: 20+ derin felsefi alıntı ve bağlamları
  • data/concepts.json: 13 temel konukseverlik kavramı ve ilkeleri
  • data/timeline.json: MÖ 2100'den günümüze tarihsel dönüm noktaları
  • data/traditions.json: Kültür ve coğrafya bazlı gelenek atlası
  • data/bibliography.json: Akademik kaynakça ve yayın künyeleri
